# PGA300 Programmer v0.3.3
Three selectable transports use the same PGA300 register / EEPROM driver.
- ESP32-C3: sketch firmware/esp32c3_pga300, USB CDC 115200; GPIO4 TX, GPIO5 RX, GPIO6 ACT.
- Arduino Pro Micro ATmega32U4: sketch firmware/promicro_pga300, USB CDC Serial 115200, hardware Serial1 D1 TX / D0 RX, D6 ACT. Prefer 3.3 V / 8 MHz, level-shift 5 V boards. Arduino IDE select correct board and clock; no ESP32 APIs used.
- TI PGAxxxEVM-034 + USB2ANY HPA665: original TI USB2ANY.dll, Windows local SDK helper. No modification of factory firmware, no claim of direct WebHID compatibility. SDK v2.8 API uses UART and GPIO; verify installed DLL API/bitness.
Both DIY boards require external OWI analog modulator and current demodulator. Never attach GPIO to PGA300 PWR.
USB protocol: INFO identifies ESP32-C3 / PRO-MICRO; HELLO returns PGA300-BRIDGE 2 9600; ACT, R page address, W page address value; requests are ID-prefixed, responses ID OK or ID ERR. OWI UART 9600 8N1, PGA300 sync 0x55. EVM helper translates identical commands via SDK.
## Original TI board
Reference [SLDU011B](https://www.ti.com/lit/ug/sldu011b/sldu011b.pdf) figures 17-19 and [SDK API v2.8](https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/138/2677.API-Reference-for-USB2ANY-SDK-2.8.pdf) sections 5.9, 5.10, 5.18.
The proposed EVM pin mapping from Fig. 17: GPIO7 ACT, GPIO11 OWI routing, GPIO10 VDD raise (held low), UART TX GPIO4 / RX GPIO5. Check actual board revision, jumpers, polarity, grounding, supply and activation waveform on scope before connecting a test chip. Original EVM requires external power (see guide). Timing of SDK command gaps is not guaranteed by Windows; activation pulse widths are generated by SDK GPIO_WritePulse. No automatic retry.
1. Download repository, install TI USB2ANY SDK/driver, use matching Windows Python architecture (often 32-bit for old DLL). Close original TI GUI.
2. In repository root: `python tools/usb2any_bridge.py --dll "C:\\path\\USB2ANY.dll" --confirm-evm034`
3. Open http://127.0.0.1:8765/?model=pga300 in Chrome. Select TI USB2ANY and connect. For multiple controllers use --serial.
4. Start with read-only EEPROM and ADC tests. All writes remain experimental. No firmware binaries, SDK DLL or hardware test included. Original TI EVM connection cannot be verified here; no production release.
Local HTTP service accepts requests only from same origin and loopback with token. No CORS, no external service. Close using Ctrl+C after normal disconnect.
